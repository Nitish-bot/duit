# Domain Docs

Duit is a single-context repository.

## Before exploring or changing the project

- Read the root `CONTEXT.md` and use its canonical terms in issues, tests, and code.
- Read the ADRs under `docs/adr/` that affect the work.
- If a proposal conflicts with an ADR, surface the conflict explicitly instead of silently overriding it.

`CONTEXT.md` is a glossary only. Keep implementation details and product specifications in their appropriate documents or issues. Create new terms and ADRs through the domain-modeling workflow when a real ambiguity or durable tradeoff is resolved.
